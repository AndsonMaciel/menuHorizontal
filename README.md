# Exercício - Menu Horizontal

Este repositório contém um exercício prático de **HTML e CSS** para a criação de um currículo simples com um **menu horizontal de navegação**.

## Objetivo
- Praticar a estruturação de páginas com **HTML5**.
- Utilizar **CSS3** para estilização e organização de um menu de navegação.
- Aplicar boas práticas de semântica e responsividade básica.

## Demonstração
O menu é exibido na parte superior do currículo, em formato **horizontal**, com efeito de hover:

- **Links do menu:** Github | LinkedIn | YouTube  
- **Funcionalidade:** ao passar o mouse sobre os itens, a cor de fundo muda.

## Tecnologias utilizadas
- HTML5
- CSS3

## Aprendizados
- Como transformar uma lista `<ul>` em um **menu horizontal** usando `display: inline-block` e `text-align`.
- Estilização de links com **pseudo-classes** (`:hover`).
- Organização de conteúdo de um currículo digital.
